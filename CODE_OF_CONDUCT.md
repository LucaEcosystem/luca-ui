# Code of Conduct

Luca UI is a small, maintained project. This code of conduct applies to
everyone participating in its issues, discussions, and other community spaces
— reporters, discussants, and maintainers alike.

## Expected behavior

- Be respectful, patient, and constructive.
- Assume good intent; disagree about ideas, not people.
- Keep reports and discussion focused on the problem: include reproductions,
  versions, and exact diagnostics.
- Respect the project's boundaries: Luca UI is proprietary software, it does
  not accept external code contributions, and it is a declarative layer on
  top of Luca Code rather than a second general-purpose language.
- Protect confidentiality: never ask for, post, or reuse secrets, private
  data, or proprietary application code.

## Unacceptable behavior

- Harassment, personal attacks, insults, or discriminatory language of any
  kind.
- Trolling, baiting, or deliberately repeating arguments after a decision.
- Publishing or threatening to publish private vulnerability reports before a
  fix is available (see [SECURITY.md](SECURITY.md)).
- Posting spam, advertising, or off-topic material.
- Attempting to bypass the license: redistributing the software, repackaging
  it as your own product, or soliciting modified copies.

## Enforcement

Maintainers may:

1. Ask for clarification or a more constructive framing.
2. Lock or remove off-topic, abusive, or repeated content.
3. Close issues or discussions that violate this code.
4. Ban repeated or severe offenders from the project's spaces.

If you see a violation, report it privately through the repository's
maintainers (see [SECURITY.md](SECURITY.md) for the private-reporting
channel). Do not respond to the violation publicly.

## Scope

This code covers the Luca UI repository's issues, discussions, and pull
requests. Luca Code's spaces are governed by that project's own code of
conduct.
